# Bella's Thinking Studio

**A playful, English-language thinking-skills programme for young learners.**

Bella's Thinking Studio helps children learn to examine clues, follow rules, assess reasons, explore possibilities and check their conclusions. It is designed for gradual skill development, with an emphasis on explaining *why* an answer works rather than guessing the right option.

> **Independent educational resource:** This is not an official NSW Department of Education product, is not affiliated with or endorsed by the department, and does not guarantee Opportunity Class (OC) placement or test results. Its activities are informed by broad critical-thinking and problem-solving skills relevant to OC-style reasoning.

The programme is intended to be flexible rather than a fixed-age or high-pressure test-preparation course. A useful starting rhythm is **two lessons per week, approximately 20–25 minutes each**, adjusting for the learner's interest and readiness.

## How a lesson works

1. **Discover:** Meet a new idea through a short example.
2. **Try together:** Use optional hints and a worked explanation to understand the method.
3. **Your turn:** Solve questions independently; each includes feedback explaining the answer choices.
4. **Transfer:** Apply the same reasoning in a different context.
5. **Reflect:** Record how you thought, what changed your mind and what to try next.

Answers are not revealed by default. Prompts are designed to encourage the learner to try first and inspect the reasoning afterwards.

## Progress, revision and backups

The programme stores learning records **in the browser on the device where it is used**. Depending on the browser's storage settings, this may include lesson completion, answers, hints used, revision status and reflection notes.

- Reopening the programme in the **same browser and site origin** should normally retain progress, provided browser storage has not been cleared or blocked.
- **Progress does not automatically sync** across phones, tablets, computers or different hosting domains.
- To switch devices, use **Settings & Backups → Export** to save a progress file, then **Import** that file on the other device.
- Keep backup files private: they may contain written reflections or learning history.
- Deleting browser/site storage, using private browsing, changing the site address, or switching browsers can make locally saved progress unavailable.
- Importing a backup may replace current saved progress. Export a backup first if you want to keep it.

**Important:** An offline HTML file and an online site usually have different browser storage locations. Use export/import to move progress between them.

## For parents and educators

- Ask **“What do we know?”**, **“What are we assuming?”** and **“How can we check?”** before giving an answer.
- Let learners explain through words, drawings, objects or a short table.
- Use hints progressively instead of telling them which option to select.
- Celebrate checking, reconsidering and finding a counterexample—not just quick correct answers.
- If reading an English question is difficult, read it aloud and distinguish language difficulty from reasoning difficulty.
- Review *how* the child reached the answer, not only whether it was correct.

This is a learning aid, not a diagnostic or psychometric assessment.
